# 🔥 Universal Data Hook System

## 📌 Overview
This project is a **system monitoring and data collection framework** that gathers real-time information from the operating system, network, processes, files, and security status.

It is designed for:
- System monitoring
- Performance analytics
- AI-ready dataset creation
- Debugging and logging

⚠️ This system is for **authorized/local use only**.

---

## 🧠 Core Features

### 🖥️ System Monitoring
- CPU usage tracking
- RAM usage monitoring
- Disk usage analysis
- System uptime tracking

---

### 🌐 Network Monitoring
- Bytes sent/received
- Packet statistics
- Hostname tracking

---

### ⚙️ Process Monitoring
- Active process list
- CPU usage per process
- Memory usage per process
- Top resource-heavy processes

---

### 📁 File System Monitoring
- Local file listing
- File size tracking
- Directory scan (safe mode)

---

### 🔐 Security Check (Basic)
- Suspicious process count flag
- System health status
- Basic anomaly detection

---

### 📊 Logging System
- JSONL structured logs
- Timestamped entries
- Continuous data recording
