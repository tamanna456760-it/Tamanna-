# Tamanna Radar

Tamanna Radar is a lightweight Python-based file and code detection system designed to scan directories, detect suspicious files, analyze risky code patterns, and generate JSON reports.

---

## Features

- Recursive folder scanning
- Suspicious file extension detection
- Dangerous keyword analysis
- SHA256 file hashing
- JSON report generation
- Real-time terminal alerts
- Lightweight and fast
