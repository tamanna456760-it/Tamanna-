# BD-KING-R7 PowerHub (All-in-One System)

A safe, secure, fast automation engine for syncing, building, and running BD-KING-R7 systems.

## Features

- Auto Sync with Git
- Auto Build
- Device-Safe Installer
- Web Chat Panel (AI)
- PowerHub Helper
- Multi-device linking (legal + secure)
- Works on Windows, Linux, Android (Termux), macOS

## Tech

- Python 3.8+
- GitHub Workflows
- HTML / CSS / JS
- JSON Config System
