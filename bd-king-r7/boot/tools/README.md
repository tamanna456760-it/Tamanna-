## **Overview**

The Tamanna System Boot Tools is a **multi-device management and automation system**.  
It allows you to:  

- Detect all devices connected to the network  
- Ping devices and check their status  
- Log system activity automatically  
- Backup and sync all code and logs  
- Run self-diagnostics and basic auto-fix operations  

This system is designed to work on **Windows, Linux, and Mac**.
