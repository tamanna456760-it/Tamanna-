# Tamanna System – User Management Web App

Tamanna System is a simple, secure **user management system** built with **Python Flask**.  
It provides user registration, login, password security, and a protected dashboard.

---

## 🚀 Features

- User Registration
- User Login
- Password Hashing (Secure)
- Session-based Authentication
- Protected Dashboard
- Clean Project Structure
- Beginner & Developer Friendly

---

## 🛠️ Technologies Used

- Python 3
- Flask
- HTML (Jinja Templates)
- Werkzeug Security
