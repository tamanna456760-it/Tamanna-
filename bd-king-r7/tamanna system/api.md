# Tamanna System 🔐  
### User Management & Authentication Platform

Tamanna System is a modular **Python-based user management system** designed for learning, testing, and future expansion into full platforms such as dashboards, APIs, and AI-powered systems.

---

## 🌟 Key Highlights

- Secure user authentication
- Clean & simple Flask web app
- Beginner-friendly structure
- Easy to extend (Admin, API, Database, AI)
- Safe & legal system design

---

## 🚀 Core Features

### 👤 User System
- User registration
- User login
- Password hashing
- Session-based authentication

### 🛡️ Security
- Hashed passwords
- Session protection
- Restricted dashboard access

### 🌐 Web Interface
- Login page
- Registration page
- User dashboard
