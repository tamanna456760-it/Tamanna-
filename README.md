# tamangsaru522-it Auto Fix Program

A comprehensive auto-fix program for JSON and code formatting with Git integration.

## Features

- 🔧 **Auto-fix JSON files** - Fix common JSON formatting issues
- 🤖 **Auto-commit** - Automatic Git commits with smart messages
- ⚙️ **Configurable** - Customizable settings for your workflow
- 🔒 **Git hooks** - Automatic fixes before commits

## Quick Start

```bash
# Clone and setup
git clone <your-repo-url>
cd tamangsaru522-it-auto-fix
npm install

# Setup environment
npm run setup

# Run auto-fix
npm run fix

# Auto commit
npm run commit "feat: add new feature"
