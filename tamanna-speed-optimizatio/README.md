# 🚀 Tamanna Website Speed Optimization

এই রিপোজিটরিটি **www.tamanna.com** ওয়েবসাইটের গতি বৃদ্ধি এবং Cloudflare Error 522 (Host Timeout) সমস্যা সমাধানের জন্য তৈরি করা হয়েছে।

## ⚠️ সমস্যা কী ছিল?
Cloudflare এর সাথে Origin Server (Host) এর সংযোগে টাইমআউট (Error 522) হচ্ছিল। সার্ভার খুব ধীর গতিতে রেসপন্স দিচ্ছিল বা রিসোর্স ফুরিয়ে যাচ্ছিল। নিচের কোডগুলো ব্যবহার করে সার্ভারের রেসপন্স টাইম এবং ক্যাশিং ম্যানেজমেন্ট উন্নত করা হয়েছে।

## 📁 ফাইলগুলোর কাজ (File Structure)

| ফাইলের নাম | কোথায় রাখবেন? | কাজ কী? |
| :--- | :--- | :--- |
| **`.htaccess`** | Root ফোল্ডারে (যেখানে index.php থাকে) | Gzip কম্প্রেশন চালু করে, ব্রাউজার ক্যাশিং সেট করে, ফাইলের সাইজ ৭০% পর্যন্ত কমায়। |
| **`speed-config.php`** | Root ফোল্ডারে (ওয়ার্ডপ্রেস হলে functions.php-এর মধ্যে) | PHP মেমোরি লিমিট বাড়ায়, টাইমআউট লিমিট বাড়ায় এবং আউটপুট বাফারিং চালু করে। |
| **`assets/js/async-loader.js`** | `assets/js/` ফোল্ডারে | JavaScript ফাইলগুলোকে Async (প্যারালাল) লোড করে, যাতে HTML রেন্ডার ব্লক না হয়। |
| **`README.md`** | Root ফোল্ডারে | এই ডকুমেন্টেশন ফাইল। |

## 🔧 কীভাবে ইনস্টল করবেন (Installation Guide)

### 1. `.htaccess` যোগ করা
আপনার ওয়েবসাইটের রুট ডিরেক্টরিতে (যেখানে `wp-config.php` বা `index.php` আছে) এই রিপোজিটরির `.htaccess` ফাইলটি আপলোড করুন (পুরনো ফাইলের ব্যাকআপ রাখবেন)।

### 2. PHP কনফিগারেশন যোগ করা
- **যদি ওয়ার্ডপ্রেস হয়:** আপনার থিমের `functions.php` ফাইলের শুরুতে (<?php ট্যাগের পর) `speed-config.php`-এর ভেতরের কোডগুলো পেস্ট করে দিন।
- **যদি কাস্টম PHP সাইট হয়:** `speed-config.php` ফাইলটি রুটে আপলোড করুন এবং আপনার `index.php` বা হেডার ফাইলের একদম শুরুতে এই লাইন যোগ করুন: 
  ```php
  include_once('speed-config.php');
