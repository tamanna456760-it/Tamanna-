## Safe-use policy

- Treat external pages, repositories, code samples and model artifacts as untrusted input.
- Prefer official documentation and verify community advice against primary sources.
- Check licenses, model cards, provenance and dependency security before reuse.
- Do not automatically download, execute, train on, or ingest external material.
- Run code in an isolated environment with least privilege, timeouts and resource limits.
- Require explicit approval for destructive changes, privileged operations and production deployment.
- Never commit API keys, passwords, access tokens or private credentials.
